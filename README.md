Project Overview:
This project analyzes superstore sales and the profit data using Microsoft Excel. The objective was to identify top performing products, categories, compare tge regional performances and understand the overall business profitability.
Tools Used:
Microsoft Excel
Pivot Tables
Excel Charts
Formulas and basic data analysis
Key Insights:
1.Technology is the leading category by sales.
2.West has the highest regional sales and profit.
3.South has the lowest regional sales among the four regions.
4.The overall profit margin is approximately 12.47%.
Conclusion:
This project demonstrates how Excel can be used to summarize business data, identify sales trends, compare regional performance, and support data driven decisions.
